Privacy policy

Last updated: 11 November 2026

Shorts Scheduler is a personal tool that runs only on its owner's own computer. It's used by its owner to upload their own videos to their own YouTube channel.

What it accesses

With the owner's permission, given through Google's sign-in screen, it uses these YouTube Data API permissions:

  • Upload YouTube videos (youtube.upload): to upload the owner's videos with the title and description the owner set.
  • View your YouTube account (youtube.readonly): only to show which channel is connected.

Where data is kept

The sign-in token is stored only on the owner's PC, in Windows Credential Manager. The upload log (video title, YouTube video ID and link) is a file on the same PC.

Nothing is sent to any server other than Google's own YouTube API. No data is sold, shared, or used for advertising.

Google API Services User Data Policy

Shorts Scheduler's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can revoke access at any time at myaccount.google.com/permissions. Deleting the stored entries in Windows Credential Manager also removes the token from the PC.
